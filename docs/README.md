## Common Tasks

### Add New Page

1. Read [architecture/ROUTING_SYSTEM.md](architecture/ROUTING_SYSTEM.md)
2. Read [architecture/FILE_ORGANIZATION.md](architecture/FILE_ORGANIZATION.md)
3. Create page component
4. Update `src/pages/index.jsx`
5. Test routing

### Add New Module

1. Read [MODULES_SYSTEM.md](MODULES_SYSTEM.md)
2. Copy `src/modules/_template/`
3. Update manifest.json
4. Implement module logic
5. Create Netlify function
6. Test all access levels

### Add New Netlify Function

1. Read [architecture/NETLIFY_FUNCTIONS.md](architecture/NETLIFY_FUNCTIONS.md)
2. Create function file
3. Configure in `netlify.toml`
4. Test locally with `npm run dev:netlify`
5. Deploy and verify

### Apply Database Migration

1. Read [BUSINESS_BRAIN_INTEGRATION_GUIDE.md](BUSINESS_BRAIN_INTEGRATION_GUIDE.md)
2. Review migration SQL file
3. Run migration script
4. Verify tables created
5. Test functionality

### Deploy to Production

1. Read [DEPLOYMENT.md](DEPLOYMENT.md)
2. Check [guides/DEPLOYMENT_CHECKLIST.md](guides/DEPLOYMENT_CHECKLIST.md)
3. Run tests and linting
4. Push to master branch
5. Monitor deployment
6. Verify production
