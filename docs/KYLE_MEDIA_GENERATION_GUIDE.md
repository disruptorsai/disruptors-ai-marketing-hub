- **Audio**: Silent or very subtle background audio

## Optimization Workflow

### After Generating Images

1. **Export from Midjourney**:
   - Always upscale to maximum resolution
   - Download at highest quality available

2. **Optimize with TinyPNG** (or similar):
   - Visit tinypng.com
   - Upload generated images
   - Download compressed versions
   - Verify quality hasn't degraded

3. **Convert to WebP**:
   - Use CloudConvert.com or Squoosh.app
   - Keep JPG as fallback
   - Both formats should be under target file size

4. **Test Performance**:
   - Check page load times with new images
   - Ensure lazy loading is working
   - Verify images look crisp on retina displays
