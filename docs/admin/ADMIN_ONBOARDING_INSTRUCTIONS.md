## 💡 Pro Tips

1. **Bookmark the Admin Panel**: Save `/admin/secret` for quick access
2. **Use Keyboard Shortcut**: `Ctrl+Shift+D` is the fastest way in
3. **Generate Test Data**: Run `npm run telemetry:generate` to see dashboard with data
4. **Check User List**: Run `npm run admin:list-users` to see all admin users
5. **Grant More Admins**: Run `npm run admin:setup-role <email>` to add more admins

## 🆘 Troubleshooting

### "Invalid email or password"
- Double-check you're using the correct email
- Make sure caps lock is off
- Try the "Forgot Password" flow
- Or use the quick access code: `nexus`

### "Access denied - Admin role required"
- Your account exists but doesn't have admin role
- Contact Will or Kyle to run: `npm run admin:setup-role <your-email>`

### Can't find the admin panel
- Try keyboard shortcut: `Ctrl+Shift+D`
- Or navigate directly to: `/admin/secret`
- Make sure you're on the correct website

### Onboarding modal won't go away
- Click "Skip" or "Got it!" to dismiss
- Or press the X button in top-right corner
- The modal only shows once per user
