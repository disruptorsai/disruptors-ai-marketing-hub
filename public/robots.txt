# Internal/demo/auth-gated tool routes (/demos/*, /connectqr1/*, /app/*, and
# the standalone tool pages) are intentionally NOT disallowed here. They carry
# an X-Robots-Tag: noindex header instead (see netlify.toml) - Google's own
# guidance is to prefer noindex over Disallow for pages you want excluded from
# search, since Disallow stops crawling before the crawler ever sees a noindex
# directive, which can paradoxically leave a blocked URL indexed with no
# snippet if it's linked from elsewhere.
