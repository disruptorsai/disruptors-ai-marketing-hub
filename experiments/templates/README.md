# Experiment Templates

## Available Templates

### concept-template.md
The main template for submitting structured experiment concepts. Use this when you want to provide detailed, organized information about your experiment idea.

**When to use**: You have a well-thought-out idea and want to provide comprehensive details.

### Quick Start Template (coming soon)

## Template Usage

### Option 1: Copy Template to Submissions
```bash
cp templates/concept-template.md submissions/my-experiment.md
# Edit my-experiment.md
# Save and wait for agent analysis
```

### Option 2: Use Ideas Folder (Recommended for Beginners)
```bash
# Just write your raw thoughts
echo "My idea is..." > ideas/my-idea.txt
# Agent will fill out the template for you
```

## Template Philosophy

Templates exist to:
1. **Ensure consistency** - All experiments have same info structure
2. **Prompt thinking** - Questions make you think through details
3. **Enable automation** - Structured data helps agent analyze
4. **Facilitate review** - Reviewers know what to look for

But they shouldn't be barriers. If templates feel overwhelming:
- Use the `ideas/` folder for raw thoughts
- Let the agent do the structuring
- Focus on the problem and value, not the format

## Creating Custom Templates

You can create domain-specific templates:
- Email marketing experiments
- Pricing experiments
- Content experiments
- UX experiments

Just follow the same general structure:
1. Overview
2. Problem statement
3. Proposed solution
4. Target audience
5. Success metrics
6. Technical requirements

---

**Templates are tools, not rules. Use what helps you think.**
